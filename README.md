# 여울 — 작은 물속의 일상

외부 모델·이미지·텍스처·폰트·오디오 에셋 없이 실행되는 3D 어항 게임입니다. Three.js(WebGL 2)를 렌더링 엔진으로 사용하고 물고기, 수초, 돌, 수면과 재질은 JavaScript 및 코드에 포함된 GLSL로 생성합니다. 물소리는 Web Audio로 합성합니다. HTML은 진입점, CSS는 UI 스타일에만 사용합니다. 라이브러리 설치 후에는 외부 서버에 요청하지 않습니다.

## 실행

Node.js 18 이상에서 처음에는 `npm ci`, 이후 `npm start` 후 http://localhost:4173 을 열어주세요. WebGL 2를 지원하는 브라우저가 필요합니다. `npm test`로 게임 규칙 테스트를 실행합니다.

## Vercel 배포

저장소 루트의 `vercel.json`이 `npm ci` → `npm run build` → `dist` 정적 배포를 설정합니다. Vercel의 Root Directory는 저장소 루트(`.` 또는 빈 값)로 두세요. `server.js`는 로컬 개발용이며 배포 시 서버 함수가 필요하지 않습니다.

빌드는 게임 코드와 필요한 Three.js 모듈·라이선스를 `dist/vendor/three`에 포함하고 import map을 배포 경로로 바꿉니다. 배포 환경에서 `node_modules`를 직접 요청하지 않습니다. 이미지·모델 에셋은 추가하지 않습니다.

로컬 배포 검증: `npm run build` 후 `npm run preview`를 실행하고 http://localhost:4174 를 여세요. 다른 정적 호스팅에서도 `dist` 폴더만 업로드하면 됩니다. `npm test`는 게임 규칙과 배포 결과물 구성을 함께 검증합니다.

## 플레이

- F 또는 먹이 주기 → 어항 클릭. 먹이를 먹으면 포만감과 성장도가 올라갑니다.
- 물 갈기: 20 코인으로 남은 먹이를 모두 제거하고 수질을 100으로 회복합니다. 수질이 높아도 먹이가 남아 있으면 물을 갈 수 있습니다.
- 수초 심기 → 원하는 모래 바닥 클릭: 미리보기가 초록색인 자리에 놓이며, 배치할 때만 40 코인을 사용합니다. 돌·유리벽 가까이·기존 수초와 겹치는 자리는 피해주세요. Esc 또는 심기 버튼으로 취소할 수 있고, 배치한 위치는 자동 저장됩니다. 수초는 최대 12포기, 물고기는 최대 16마리입니다.
- 건강한 물고기는 30초마다 3 코인을 선물합니다. 돌봄 일지 보상으로도 코인을 얻습니다.
- 물고기를 클릭하면 개별 상태가 표시됩니다. Space로 일시 정지합니다.
- 드래그로 3D 어항을 회전하고 휠 또는 두 손가락으로 확대합니다. 먹이 모드에서는 카메라 회전을 멈춥니다.
- ‘수면 가까이 보기’로 반사와 굴절을 관찰하고, 물결·빛 반사 슬라이더로 세기를 조절합니다. 수면 클릭 또는 ‘파문 만들기’로 물결을 일으킵니다.
- 조명, 합성 물소리, 전체 화면, 도감을 지원합니다.
- localStorage에 10초마다 저장합니다. 닫거나 숨겨둔 시간은 진행하지 않습니다. 같은 브라우저·주소로 돌아오면 이어집니다.

## 구현과 참고

[ScottieFox/caustic-volume](https://github.com/ScottieFox/caustic-volume)의 수면 파동 및 굴절 전후 면적 비율을 이용한 카스틱 기법을 참고해 새로 구현했습니다. 원본 소스나 에셋을 복제하지 않았습니다.

- 서로 다른 방향·파장의 파동 24개와 GPU 높이장 시뮬레이션을 사용합니다. 클릭 파문은 주변으로 전파되고 유리벽에서 반사되어 감쇠하며, 작은 여과기 흐름이 잔물결을 만듭니다.
- 매 프레임 생성한 하나의 수면 높이·기울기 텍스처를 수면 메시, 움직이는 수면 가장자리, 굴절, 반사, GPU 카스틱 패스가 공유합니다.
- 수면 격자에서 굴절한 광선을 바닥으로 투영하고, 삼각형의 면적 비율로 집중되는 빛을 계산해 별도 렌더 타깃에 누적합니다.
- 수면에서는 Snell 굴절 방향을 따라 장면 깊이 버퍼를 탐색하고, Fresnel 반사와 Beer–Lambert 색 흡수를 적용합니다. 유리 정면은 실루엣 중복을 피하도록 깊이 기반 색 흡수로 근사합니다.
- 창문·하늘·조명 반사 환경도 코드로 생성합니다. 화면 공간 굴절은 화면 밖·가려진 물체에 대한 정보가 없어 출구 좌표로 근사하며, 원본의 다중 내부 반사 및 전체 체적 광선 추적과 동일하지 않습니다. 부동소수점 렌더 타깃 미지원 GPU에서는 해석적 파동은 유지하지만 파문 시뮬레이션을 생략합니다.
- 물고기 몸통은 단면 기반 3D 메시이며 무늬·비늘은 셰이더, 지느러미와 지느러미살은 반투명 메시입니다. 몸통·꼬리·가슴지느러미가 움직이고 깊이 방향으로 헤엄칩니다.
- 돌, 모래, 수초, 유리 가장자리와 조명도 절차적으로 생성합니다. 도감은 같은 3D 모델을 다시 렌더링합니다.
- 기존 `yeoul-v1` 저장 데이터를 이어서 사용합니다.

상상 속의 어항이므로 해수어와 담수어가 함께 생활하며 수온은 26°C 고정입니다. 실제 사육 안내가 아닙니다.

파일: `src/game.js` 게임 규칙·저장 검증 / `src/scene3d.js` 3D 장면·카메라·상호작용 / `src/water-surface.js` 파동 스펙트럼·GPU 시뮬레이션 / `src/optics.js` 굴절·반사·카스틱 / `src/fish3d.js` 물고기 메시·재질 / `src/habitat.js` 절차적 환경 / `src/main.js` UI / `src/style.css` 반응형 스타일.
